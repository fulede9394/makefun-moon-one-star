A one-star review of the Moon, written for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5) "The Moon Gets One Star" ($2).

The entry is a deadpan hotel-style review: one star, a grievance about the Moon itself (4.5 billion years up there and it still hasn't fixed the lighting, and it vanishes for days without telling anyone), in 117 characters — inside the 120-character gate.

Run it with `node main.ts`; it writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and verifies the file round-trips byte-identically.
